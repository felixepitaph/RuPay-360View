# Wiki: playbooks (learned patterns)

Entries are added only by approved proposals from the Learning Steward or Impact Analyst, after analysts confirm the underlying findings. Each entry is a reusable expectation that helps the Investigator and Writer.

Format:
```
### PB-001: <pattern name>
Evidence: finding IDs (3+ CORRECT), date range, issuers
Pattern: what happens, typical size and duration (numbers from the findings, with IDs)
Use: what to check first next time; recommendation if any
Status: ACTIVE | RETIRED (reason)
```
